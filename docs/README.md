## 🚀 Running Locally
Open `index.html` directly in any web browser. All styles, scripts, and images load locally from their respective folders.

## 🌐 Deploying
- **GitHub Pages**: Push this directory to a GitHub repo and enable Pages under Settings.
- **Vercel / Netlify**: Drag-and-drop this entire folder for an instant live HTTPS link.
